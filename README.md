## Was ist das?

Green Horizons ist ein 3D-Stadtbausimulator in der Tradition von SimCity.
Der Spieler baut eine Stadt, trifft dabei aber Entscheidungen die den
CO2-Fußabdruck der Stadt beeinflussen. Ziel ist es, eine wachsende,
glückliche Stadt aufzubauen – ohne die Umwelt zu zerstören.

Jedes Gebäude, jede Straße und jede Energieentscheidung hat Konsequenzen.
Erneuerbare Energien senken den CO2-Ausstoß, Industriegebäude erhöhen ihn.
Zufällige Ereignisse wie Dürren oder Überflutungen fordern die Stadt heraus.

---

## Features

- Freies Bauen auf einem Grid-System mit Gebäuden und Straßen
- Automatische Straßenerkennung: Ecken, T-Kreuzungen und Kreuzungen
  werden beim Ziehen automatisch platziert
- CO2-Budget-System: jede Bauentscheidung beeinflusst den Fußabdruck
- GreenCoins als Währung mit Einnahmen pro Tag und Gebäude
- Zufriedenheitssystem mit visueller Rückmeldung
- Erneuerbare Energien: Wind, Solar, Wasser
- Zufallsereignisse: Dürren, Überflutungen, Hitzewellen, politische Unruhen
- Tag/Nacht-Zyklus
- Pause-Menü mit Slide-Animation
- Einstellungen: Auflösung, Grafik, Lautstärke, Vollbild

## Installation

1. Repository klonen:
   ```
   git clone https://github.com/Keradean/Green-Horizon.git
   ```
2. Unity Hub öffnen → **Add project from disk**
3. Unity Version **6000.4.5f1** auswählen
4. Projekt öffnen → Scene **Main Menu Scene** laden
5. Play drücken
